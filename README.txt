WHAT THIS PROJECT DOES:
A multimodal AI healthcare system combining Natural Language Processing (NLP), 
Computer Vision (OpenCV), and Live Geolocation (Google Maps) for offline clinical triage.

--- HOW TO RUN THE LIVE DEMO FOR EVALUATION ---

1. Prerequisites: Ensure Python is installed on your computer.
2. Open your Command Prompt (Windows) or Terminal (Mac/Linux).
3. Navigate to this project folder using the command:
   cd path/to/AuraHealth_Project

4. Install the required libraries by running:
   pip install streamlit pandas scikit-learn opencv-python

5. Launch the application by running:
   streamlit run healthcare_web.py

6. The browser will automatically open the interactive Gemini-style web interface!
